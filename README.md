# REACT UI COMPONENTS

## 📌 Project Overview
FlowTrack360 is a responsive React application developed to demonstrate reusable React components and modern UI design. The project showcases service cards, team member cards, and a responsive layout using React components with professional CSS styling.

---

## 🎯 Objectives

- Build reusable React components.
- Design a responsive user interface.
- Apply modern CSS styling.
- Organize the project using a component-based architecture.

---

## 🛠️ Technologies Used

- React.js
- JSX
- CSS3
- JavaScript (ES6)
- HTML5

---

## ✨ Features

- Reusable Service Component
- Reusable Team Component
- Responsive Layout Component
- Professional Glassmorphism UI
- Gradient Background
- Responsive Grid Layout
- Hover Animations
- Modern Buttons
- Mobile Friendly Design
- Clean Component Structure

---

## 📄 Components

### 1. Service Component

Displays:
- Service Icon
- Service Name
- Service Description
- Learn More Button

---

### 2. Team Component

Displays:
- Team Member Image
- Name
- Designation
- View Profile Button

---

### 3. Responsive Layout Component

Provides:
- Responsive Grid Layout
- Automatic Card Alignment
- Mobile, Tablet and Desktop Support

---

## 📱 Responsive Design

The application is fully responsive and works well on:

- Desktop
- Laptop
- Tablet
- Mobile Devices
